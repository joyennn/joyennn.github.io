About SEEK

Sentence Exploration and Extraction Kit

Desktop software for linguistic sentence extraction. Import text, inspect dependency parses, describe search conditions in natural language, and export matching sentences.

Stanza language selection · Local GPU with CPU fallback · Large-corpus processing

Which Mac version? Open the Apple menu () → About This Mac. Choose M series for an Apple M-series chip, or Intel for an Intel processor.

Security warning on first launch

The Mac preview is not Apple-notarized, and the Windows installer is unsigned. Your system may ask you to allow SEEK when installing or opening it.

Mac · M series and Intel

If Apple says it cannot verify SEEK, close the alert. Open  → System Settings → Privacy & Security, scroll to Security, and select Open Anyway for SEEK. Authenticate and select Open. These settings are on your Mac, not inside SEEK.

Windows

If SmartScreen shows “Windows protected your PC”, select More info → Run anyway. If Windows then asks to allow the installer to make changes, confirm that it is the SEEK installer before continuing.

Only proceed with files downloaded from this page’s GitHub release. These steps apply to unverified-app warnings, not a named malware detection. If no override is available on a managed computer, contact your administrator; do not disable system protection.

Installation

Mac · M series / Intel

  1. Download the version matching your Mac’s chip or processor.
  2. Open the .dmg and drag SEEK.app to Applications.
  3. Open SEEK. If blocked, follow the security warning instructions above.

Windows

  1. Save the EXE and both BIN files in the same folder.
  2. Run the EXE installer and follow the setup steps.
  3. Open SEEK from the Start menu.

Windows uses Microsoft WebView2. Selected language models download on first use. GPU: Apple MPS on supported M-series Macs; compatible NVIDIA CUDA on Windows, with CPU fallback. Intel Macs can use CPU processing.

Usage

  1. Add data. Select the corpus language, then paste text, choose a TXT file, or load CoNLL-U annotations.
  2. Parse. Use Automatic to select a compatible GPU or CPU. Inspect dependency graphs or token tables. Enter a corpus sentence number and select Go to jump to any saved sentence. Save CoNLL-U annotations for reuse. Pause and resume processing from saved batches.
  3. Build conditions. Enter your OpenAI API key in Connect AI. Describe the target construction and select Build conditions with AI.
  4. Search and export. Review and confirm the interpreted conditions, then select Run search. Export matching sentences as TXT or CSV.
Download sample annotations (.conllu) ↓

Large corpora: No corpus sentence or file-size cap. Files are processed in batches and saved locally. Screen pagination does not limit search or exports. Available disk and hardware resources determine capacity. Oversized or malformed individual passages require review.

API usage: New AI-generated conditions use your own API key and billing. Parsing and running saved conditions require no API call. ChatGPT login does not supply an API key.

Data: Parsing and search run locally. Only the construction description, query schema, and corpus language are sent to OpenAI. The API key is cleared when the interface reloads.

Review: Check parser output and AI interpretations. Structural matches may require further linguistic judgment.
